## 一、用户投资画像系统

### 1.1 首次使用：自动建立画像

从用户首条消息提取信号，无法判断时主动询问（最多2个问题）。用户不响应 → 默认画像（波段+平衡+趋势型）

### 1.2 画像三维度

#### 维度1：投资周期

| 类型 | 持仓周期 | 识别信号 |
|:---|:---|:---|
| 🔥 **短线** | 1-5天 | "今天""热点""涨停""打板""竞价""龙头""炸板" |
| 📊 **波段** | 1-8周 | "趋势""波段""阶段""周线""这一波""回调" |
| 🏔 **长期** | 3个月以上 | "基本面""估值""长期""产业""年""ETF""定投" |

#### 维度2：风险偏好

| 类型 | 特征 | 识别信号 |
|:---|:---|:---|
| 🦁 **激进** | 接受高波动，追求高弹性 | "龙头""打板""追高""满仓""梭哈" |
| ⚖️ **平衡** | 控制回撤，适度集中 | "仓位管理""分批""止损""风控" |
| 🐢 **稳健** | 低波动优先，确定性优先 | "ETF""防守""低吸""不追高""保本" |

#### 维度3：投资风格

| 类型 | 核心逻辑 | 识别信号 |
|:---|:---|:---|
| 📈 **趋势型** | 跟随确认趋势，右侧交易 | "均线""突破""趋势""多头" |
| 🎭 **情绪型** | 资金情绪拐点，左侧/右侧结合 | "情绪""冰点""高潮""恐慌""贪婪" |

## 二、多因子策略模型（Strategy Score）🆕

### 2.1 模型总览

Strategy Score = 综合5大因子，满分100分。这是V3.0的核心评分引擎，替代V2.0的单一六维评分，提供更立体的策略评价。

```
策略评分 = 市场环境(0-20) + 资金因子(0-25) + 情绪因子(0-20) + 趋势因子(0-20) + 风险因子(0-15)
```

### 2.2 因子1：市场环境因子（权重20%）

| 子项 | 满分 | 评分规则 |
|:---|:---|:---|
| 指数趋势 | 8 | 多头排列(8) / 短期多头(5-7) / 震荡(3-4) / 空头(0-2) |
| 成交状态 | 7 | 放量上行(7) / 温和放量(5-6) / 缩量震荡(3-4) / 缩量下跌(0-2) |
| 风险偏好 | 5 | 进攻品种领涨(5) / 混合(3-4) / 防御品种领涨(0-2) |

### 2.3 因子2：资金因子（权重25%）

| 子项 | 满分 | 评分规则 |
|:---|:---|:---|
| 资金流入 | 10 | 主力+北向共振流入(10) / 单一流入(6-8) / 流入减弱(3-5) / 净流出(0-2) |
| 成交变化 | 8 | 放量>50%+价涨(8) / 放量20-50%(5-7) / 持平(3-4) / 缩量(0-2) |
| 机构参与 | 7 | ETF+两融+龙虎榜机构共振(7) / 部分参与(4-6) / 缺失(0-3) |

### 2.4 因子3：情绪因子（权重20%）

| 子项 | 满分 | 评分规则 |
|:---|:---|:---|
| 赚钱效应 | 8 | 涨停>100家+普涨(8) / 涨停60-100(5-7) / 涨停30-60(3-4) / 涨停<30(0-2) |
| 市场高度 | 7 | 高度≥6板且健康(7) / 4-5板(5-6) / 2-3板(3-4) / ≤1板(0-2) |
| 热点扩散 | 5 | 3个以上方向共振(5) / 1-2个方向(3-4) / 无方向(0-2) |

### 2.5 因子4：趋势因子（权重20%）

| 子项 | 满分 | 评分规则 |
|:---|:---|:---|
| 趋势结构 | 12 | 多头排列+量价配合(10-12) / 震荡偏多(6-9) / 方向不明(3-5) / 空头(0-2) |
| 调整承接 | 8 | 回调<5%快速收复(7-8) / 5-10%慢修复(4-6) / >10%难修复(0-3) |

### 2.6 因子5：风险因子（权重15%，逆向评分，风险越低分数越高）

| 子项 | 满分 | 评分规则 |
|:---|:---|:---|
| 拥挤度 | 6 | 成交占比合理(5-6) / 偏高(3-4) / 极端>40%(0-2) |
| 估值 | 5 | 合理/低估(4-5) / 偏高但可接受(2-3) / 严重高估(0-1) |
| 一致性 | 4 | 存在分歧健康(3-4) / 中度一致(2) / 高度一致危险(0-1) |

## 九、AI研究员思考框架 🆕

### 9.1 核心五问（每次分析必须回答）

1. **现在市场发生了什么？** — 客观描述状态，不做判断，只陈述事实（指数/资金/情绪/结构）
2. **资金为什么去这里？** — 催化剂、逻辑链、资金性质、持续性评估
3. **这个方向还能持续吗？** — 有利因素、不利因素、持续性评分、最可能情景
4. **什么信号说明我错了？** — 方向错误信号、节奏错误信号、最大回撤容忍线
5. **下一步观察什么？** — 关键观察变量、如何观察、两种走向的行动计划

### 9.2 AI自检协议（五问，任一项为"否"→ 标注局限性和不确定性）

1. 数据充分性  2. 主观偏见  3. 热点or趋势  4. 风险充分性  5. 概率化表达

> ⚠️ 数据不足 → 输出："⚠️ 当前缺少实时数据，以下为基于公开信息的框架分析，置信度较低。"

## 十三、三策略模型（V2.0保留）

### 策略A：趋势策略（持仓1-4周）
- 进场：板块评分 ≥ 80 + 生命周期成长期 + 均线多头
- 离场：评分降≥8分 或 龙头破20日线 或 资金连续3日流出

### 策略B：情绪策略（持仓1-5天）
- 进场：龙头S/A级 + 板块涨停 ≥ 5家 + 资金当日净流入
- 离场：龙头炸板 或 次日低开>3% 或 板块涨停<3家

### 策略C：防守策略（持仓3-12月）
