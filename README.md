# pi-skills (public mirror)

Public mirror of the private `kore-01/pi-skills` repository, arranged for Kelivo's GitHub skill importer.

Each skill lives in its own top-level directory with a `SKILL.md` at its root. Kelivo imports one skill per URL:

    https://github.com/kore-01/pi-skills-public/tree/main/time

No credentials or secrets are stored in this repository.
