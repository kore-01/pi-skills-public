# ETF-Skill 使用指南

## 一句话

把本技能发给 AI 助手，然后直接说人话。它会按 ETF量化研究员 的规则输出。

## 最小可用流程

```
1. 先发本文件（含 SKILL.md 与 references/ 全部内容）给 AI
2. 再说你的需求，例如：
   - /扫描
   - /评分 科创50ETF
   - /定投 医药ETF
   - /网格 沪深300ETF
   - 半导体ETF现在还能追吗
3. AI 会按「系统Prompt」里的输出格式给出结构化结果
```

## 数据从哪来

本技能**不自带行情接口**。需要数据时：

- 宿主若已接入股票数据技能（如 kpl-stock-data），先取数再套用本技能的评分与规则
- 或由用户直接粘贴数据（ETF代码、近5日涨幅、RSI、资金流、PE分位等）

**缺数据时不要编。** 缺 RSI / 资金流 / PE 分位，就明确列出「需要的数据字段」，等补齐再评分。

## 快捷命令

| 命令 | 用途 |
|------|------|
| `/轮动` | 行业轮动诊断（启动/主升/加速/退潮四阶段） |
| `/评分 XXXXXX` | ETF 六维评分（满分100，S/A/B/C/D 评级） |
| `/定投 XXXXXX` | 定投诊断 + 估值系数（0x ~ 2.0x） |
| `/网格 XXXXXX` | 网格参数（区间/间距/层数/每格金额/底仓） |
| `/扫描` | 每日ETF扫描（强/弱榜 + 资金流 + 轮动信号） |
| `/宽基` | 主要宽基指数ETF状态 |
| `/行业` | 行业ETF排名 |
| `/跨境` | 跨境ETF状态 + 折溢价检查 |

## 输出格式速查

| 模块 | 标题 |
|------|------|
| A 行业轮动 | 【ETF行业轮动诊断】 |
| B ETF评分 | 【ETF评分：XXXXXX（代码）】 |
| C 定投 | 【定投诊断：XXXXXX】 |
| D 网格 | 【网格交易规划：XXXXXX】 |
| E 每日扫描 | 【ETF每日扫描 YYYY-MM-DD】 |

## 铁律（AI 必须遵守）

1. 行业ETF永远选规模最大、流动性最好的那只
2. 跨境ETF折溢价 ±3% 以上必须警示
3. 行业ETF不比个股安全多少——行业退潮一样跌30%+
4. 定投止盈不止损（+30%减仓50%，+50%清仓）
5. 网格只在震荡市有效
6. 宽基底仓50-70% + 行业进攻30-50%，不要全仓行业ETF

## 数据源

本技能的知识库更新到 2026-07-03。涉及「当前行情」的部分（2026上半年涨幅、7/3收盘快照）会过期 —— 每次用之前用实时数据刷新，不要直接引用知识库里的历史数字当现状。
