# ETF定投与网格交易策略（2026实战版）

> 定投和网格是ETF投资者的两大利器。
> 定投解决"什么时候买"的问题，网格解决"震荡市怎么赚钱"的问题。
> 两者配合使用，可以覆盖80%的市场环境。

---

## 一、智能定投策略

### 1.1 定投的核心数学

传统定投：每月固定金额买入 → **傻傻买**
智能定投：根据估值调整金额 → **聪明买**

**为什么智能定投更优？**

| 估值分位 | 传统定投 | 智能定投 | 差异 |
|---------|---------|---------|------|
| 低估（＜30%） | 1000元 | **2000元** | 多买1倍 |
| 正常（30-70%） | 1000元 | 1000元 | 相同 |
| 高估（＞70%） | 1000元 | **0元（暂停）** | 少买100% |

> 长期来看，智能定投的年化收益比传统定投高3-5个百分点。

### 1.2 定投标的怎么选

**定投最适合的ETF类型**：
✅ 宽基指数ETF（沪深300、科创50）—— 长期向上，不会归零
✅ 高波动行业ETF（半导体、医药）—— 波动大=定投摊低成本的效果好
⚠️ 强周期行业ETF（煤炭、有色）—— 周期顶部开始定投=地狱模式
❌ 单一赛道ETF（过于细分）—— 有全军覆没风险

**定投选择标准**：
1. 指数长期趋势向上（不会归零）
2. 波动率适中（年化波动20%-40%最佳）
3. PE/PB估值有历史数据可参考
4. ETF规模≥5亿（不会清盘）

### 1.3 定投金额公式

```
本期定投金额 = 基准金额 × 估值系数 × 趋势系数

估值系数（基于PE/PB分位）：
  PE分位 ＜ 10%   → 2.0x（极度低估，加倍买）
  PE分位 10-30%  → 1.5x（低估，适度加码）
  PE分位 30-50%  → 1.0x（合理偏低，正常买）
  PE分位 50-70%  → 0.5x（合理偏高，减半买）
  PE分位 ＞ 70%  → 0x（高估，暂停买入）

趋势系数（基于均线）：
  价格在60日线上方 → 1.0x（趋势向上，正常买）
  价格在60日线下方 → 1.2x（超跌，适当多买）
```

### 1.4 止盈策略

**不止盈的定投=坐过山车。**

| 累计收益 | 操作 |
|---------|------|
| +20% | 关注，开始留意市场情绪 |
| +30% | **减仓50%**（锁定一半利润） |
| +50% | **清仓**（全部止盈，等下一轮低估） |
| PE分位＞80% | 无论收益率多少，**逐步卖出** |

**止盈后的资金安排**：
- 转入货币ETF → 等待下一轮低估→重新开始定投
- 或转入其他仍在低估区间的ETF → 接力定投

## 二、网格交易策略

### 2.1 什么是网格交易

把资金分成N等份，在价格区间内等间距挂买单和卖单：
- 跌一格 → 买一份
- 涨一格 → 卖一份
- 反复震荡 → 反复收割

**核心赚钱逻辑**：赚的是波动的钱，不是趋势的钱。

### 2.2 什么ETF适合做网格

✅ **适合网格的ETF**：
- 宽基指数ETF（沪深300ETF、科创50ETF）→ 箱体震荡时最好
- 高流动性ETF（日均成交>1亿）→ 确保买卖顺畅
- 波动率适中的ETF（年化波动15-30%）

❌ **不适合网格的ETF**：
- 单边上涨趋势的ETF → 网格踏空
- 单边下跌趋势的ETF → 网格越套越深
- 日均成交＜5000万的ETF → 流动性不足
- T+0跨境ETF → 日内波动太大，网格容易被打穿

### 2.3 网格参数计算器

**Step 1：确定价格区间**
```
上限 = 近期高点 × 1.0（或略高2-3%）
下限 = 近期低点 × 0.95（留一点安全垫）
```

**Step 2：确定网格间距**
```
波动率＜20% → 间距3%（窄幅震荡，细网格）
波动率20-30% → 间距4%（正常波动，中网格）
波动率30-40% → 间距5%（宽幅波动，粗网格）
波动率＞40% → 不建议做网格（波动太大容易穿）
```

**Step 3：计算网格层数**
```
层数 = (上限 - 下限) / 下限 / 间距
总资金 = 底仓金额 + (层数 × 每格金额)
```

**Step 4：计算每格金额**
```
每格金额 = (总资金 - 底仓金额) / 层数
```

### 2.4 网格实战示例

```
【示例】科创50ETF 网格交易方案

📊 参数设定：
   当前价格：1.200元
   价格区间：1.080 ~ 1.320（±10%）
   网格间距：3%（36档）
   网格层数：9层
   每格金额：2000元
   底仓：10000份（1.2万元，50%仓位）
   总投入：1.2万（底仓）+ 1.8万（网格）= 3.0万元

📈 预期收益：
   每格收益：3% × 2000元 = 60元/次（扣除手续费后约55元）
   保守估计月成交4次 → 220元/月 → 年化约8.8%

⚠️ 风险预案：
   跌破下限1.080 → 暂停网格，观察是否转趋势下跌
   突破上限1.320 → 底仓吃趋势，暂停网格
```

### 2.5 网格风险与应对

| 风险 | 表现 | 应对 |
|------|------|------|
| 单边下跌 | 不断触发买入，资金耗尽 | 跌破下限→暂停网格，不追加资金 |
| 单边上涨 | 不断触发卖出，底仓卖光 | 突破上限→保留底仓吃趋势 |
| 波动收窄 | 长期不触发买卖 | 缩小间距或换标的 |
| 流动性枯竭 | 挂单无法成交 | 换日均成交>1亿的标的 |

## 三、定投+网格组合策略

**核心思路**：底仓用定投积累，震荡用网格增厚收益。

```
资金分配：
  70% → 定投仓位（长期持有，只在极度高估时卖出）
  30% → 网格仓位（震荡市赚钱，趋势市暂停）

操作节奏：
  定投：每月执行1次（按估值系数调整金额）
  网格：每日自动运行（或每周手动调整）

什么时候只用定投？
  → PE分位＜30%（低估区间，多买少卖）

什么时候定投+网格一起用？
  → PE分位30-70%（合理区间，震荡为主）

什么时候暂停定投+停止网格？
  → PE分位＞70%（高估区间，只卖不买）
```
